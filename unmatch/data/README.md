Dataset to replicate the data example from You & Rao (2002) 'Small Area
Estimation using unmatched Sampling and Linking Models'

Data and sources are:

- Undercoverage estimates and CV pulled from Table 2 from You, Rao (2002)

- 1991 Census data for Canadian provinces from 
  <https://www12.statcan.gc.ca/english/census91/data/profiles/Profiles.cfm>
  Click on 'Profile of Census Divisions and Subdivisions - Part A'
  Select the corresponding provinces and use the value from 'Population, 1991 (2)'
